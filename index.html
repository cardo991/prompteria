TU MARCA, TAMBIÉN EN TUS REPORTES
Power BI merece su propio estilo
Llevá la identidad visual de tu marca a Power BI Desktop. Elegí un estilo arriba o creá el tuyo y descargá un tema listo para importar.

    

      

        TEMA PARA POWER BI DESKTOP
        

        
Una paleta consistente para tus gráficos, fondos y textos, con tipografías y formato base para los visuales.

        

        
Gráficos
8 colores para series de datos
Indicadores
Colores positivos, neutros y negativos
Reporte
Fondos, bordes, títulos y etiquetas

        
        
El archivo aplica formato visual. Los datos, las medidas y la distribución del reporte los definís en Power BI.

      

      

        
Del estilo al reporte, en tres pasos

        
  1. Elegí tu identidad
    Usá el selector de estilos de arriba. Para tu marca, creá una paleta en «Tu estilo» y tocá «Probar en la página».
  2. Descargá el tema
    Guardá el archivo .json desde esta sección. Si estás creando una paleta, también podés descargarla directamente desde «Tu estilo».
  3. Importalo en Power BI Desktop
    Abrí tu reporte y entrá en Vista → Temas → Examinar temas. Seleccioná el archivo descargado.

        
Los visuales con formato manual pueden conservar sus colores. Restablecé su formato para que hereden el tema. La vista de la galería es una referencia del estilo; el resultado depende de los visuales de tu reporte.

        Guía de temas de Microsoft ↗

MCP server
Conectá Promptería a tu agente y pedile cosas como "aplicá el estilo Bento claro a este proyecto".

    

      

        
Instalación

        
npx -y prompteria mcp

        
O cloná el repo y usá node mcp/server.mjs.

        
Claude Code

        
claude mcp add prompteria -- npx -y prompteria mcp

        
Codex (~/.codex/config.toml)

        
[mcp_servers.prompteria]
command = "npx"
args = ["-y", "prompteria", "mcp"]

        
Cursor y Claude Desktop

        
{
  "mcpServers": {
    "prompteria": {
      "command": "npx",
      "args": ["-y", "prompteria", "mcp"]
    }
  }
}

        
Para probarlo a mano: npm run inspect.
